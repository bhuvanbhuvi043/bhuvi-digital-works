# Bhuvi Digital Works

Official portfolio and digital studio site for Bhuvaneshwaran R, based in Chennai, India.

The site is built with React, TypeScript and Vite, and deployed to GitHub Pages at [bhuvanbhuvi043.github.io/bhuvi-digital-works](https://bhuvanbhuvi043.github.io/bhuvi-digital-works/). The build writes the compiled site to the repository root as well as `dist/`, so both branch based Pages and the Actions artifact serve browser-ready JavaScript.

## Local development

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`. GitHub Actions publishes the `dist` directory to Pages whenever `main` is updated.

## Brand assets

- `public/assets/bhuvi-digital-works-logo.svg` — primary full wordmark with transparent background
- `public/assets/bhuvi-digital-works-logo.png` — transparent PNG export of the wordmark
- `public/assets/bhuvi-mark.png` — optimized transparent copy of the supplied logo artwork
- `public/assets/bhuvi-mark.svg` — scalable SVG wrapper for the supplied mark

The B monogram keeps the blue identity, the pixel fade represents digital craft, and the orange circuit line represents connected technology and automation.
