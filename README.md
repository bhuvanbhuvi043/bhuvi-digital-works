# Bhuvi Digital Works

Official portfolio and digital studio site for Bhuvaneshwaran R, based in Chennai, India.

The site is built with React, TypeScript and Vite, and deployed to GitHub Pages at [bhuvanbhuvi043.github.io/bhuvi-digital-works](https://bhuvanbhuvi043.github.io/bhuvi-digital-works/).

## Local development

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`. GitHub Actions publishes the `dist` directory to Pages whenever `main` is updated.

## Site content

- Digital services: web design, SEO, AI automation and creative production
- Selected projects and open-source experiments
